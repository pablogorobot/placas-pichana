# Generador de placas IG · Brigada Pichana

Herramienta web para armar placas de Instagram de la Brigada Forestal Pichana.
Cargás etiqueta, título, texto e imágenes y descargás el PNG listo para publicar.

Todo funciona en el navegador (no sube nada a ningún servidor). Fuentes del manual
(Poppins/Lora) y logo embebidos.
